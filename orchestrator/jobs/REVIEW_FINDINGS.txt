INDEPENDENT REVIEW - orchestrator/jobs/ IS NOT PRODUCTION READY
Reviewed 2026-11-04 by gpt-6.1-sol against AGENTS.md, the PRD and the spike findings.
Implementation by gpt-6-luna; both the code and its tests were written by that one
agent, which is why 9 green tests coexist with hollow production paths.

Do not treat this package as working. The headline defects:
  - PynvmlReader exposes no total-memory accessor, so the real probe computes zero
    free VRAM and refuses every job. Tests pass only because they inject a fake.
  - unload / terminate / respawn default to no-ops, so a failed release reports
    recovery without replacing the poisoned worker - the one thing spike 03 proved
    is mandatory after a CUDA error.
  - The persisted PID is the orchestrator's, not the GPU worker's, so orphan
    detection cannot work.
  - Job state is never persisted, so a restart loses the queue.
  - FR-26 budget ceilings are not enforced at all.

Scheduled for rewrite with the implementer and the test author as SEPARATE agents.
