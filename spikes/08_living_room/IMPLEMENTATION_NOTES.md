# Living-room implementation brief

A deterministic procedural American timber-house living room, approximately 5.4 x 4.2 x 2.44 m. Drywall over timber structure (no need to expose studs), painted domestic trim, a genuine opening/frame and window/sill, ceiling and fixture. Fixed corner CCTV mount below ceiling looking across the room. Full extents in metres.

## Shared implementation and test contract

- Add `american_living_room()` to scene.py; never edit `synthetic_interior()` or change its canonical worker-plan hash.
- Composition defaults to the new builder; persisted built scenes continue to load unchanged. Existing composition pinned-hash expectation conflicts with this change: report, never edit that test without explicit adjudication.
- Extend existing specs only as needed for material textures, emission, rounded geometry, object rotation and motivated lights. New optional/default fields must be removed from old scene worker payloads so the synthetic static-plan bytes stay identical. Old artifacts remain readable.
- Proposed additive fields: MaterialSpec `surface` (plain/wood/fabric/plaster/rug), `texture_scale` Vec3, `variation` [0,1], `bump_strength` [0,1], `emission_strength` nonnegative, `metallic` [0,1]; ObjectSpec kind additionally sphere/cone/torus, `rotation` radians Vec3, `bevel` nonnegative; LightSpec `kind` area/point, `target` optional Vec3. Defaults preserve old behavior and payload. Extensions must have bounded/finite validation. Objects use local full dimensions before rotation.
- Pure builder uses fixed local random seed only; unique names, valid materials, JSON roundtrip, camera no keyframes. Grounded sofa/coffee table/TV stand/side table/shelf, rug on floor, lamp visibly motivated, cooler window and warm practical pools. Furniture components join and do not hover. Functional clutter on tables/shelves; no random primitive scattering.
- Preserve useful existing anomaly target names where plausible (Practical01/Practical02, Desk_A, Clutter_00); do not pretend target room coordinates are generally compatible. No changes to domain/API/contracts/degradation/fonts/dependencies.py.
- Worker accepts new specs without library beyond Blender/stdlib. Procedural texture nodes must be used for color/roughness as well as subtle bump; untextured defaults retain their prior material behavior. Dimensions applied before rotation, bevel clamped to geometry to avoid self-intersection. Sphere smooth shading and rounded upholstery. Every write path in harness comes from ProjectRoot containment; use runtime-contained temp and output paths for Blender.
- Verification: independently authored CPU tests for determinism, roundtrip, extents/support contacts, material reference/name integrity, static camera, non-flat material payloads, and retained synthetic canonical hash. Tests/review agents report failures, do not fix implementation or existing tests. Actual render visual review decides criterion 2; CPU tests cannot certify it.
- Harness uses production build_scene_plan and worker; measures each render wall time, device-wide NVML idle/peak/delta, actual engine/GPU metadata, per-frame times when available. Same mounted camera and lens for grey-box and living room. Retain before/after/intermediate PNG, JSON telemetry, iteration notes under spikes/08_living_room. Separate cold startup from warmed cadence; compare a sequential 60-frame render to recorded 0.323 s/frame without treating a cold still as cadence.
